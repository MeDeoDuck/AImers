# AImers

AI 면접 개념 암기 퀴즈. 아이폰 Safari에서 한 손으로 푸는 정적 웹앱.

원본: `개념 리스트.html` (면접 질문 리스트.docx 2–24쪽) — 92개 개념
섹션: Linear Algebra 13 · Machine Learning 49 · Statistics 30

## 모드

| # | 모드 | 방식 |
|---|---|---|
| 1 | 뜻 → 단어 | 영어 정의를 보고 영어 term 맞추기 (객관식 / 주관식 / 섞기) |
| 2 | 단어 → 뜻 | 영어 term을 보고 영어 정의 고르기 (객관식) |
| 3 | 매칭 O/X | term과 뜻이 바르게 짝지어졌는지 판정 → 틀렸으면 올바른 뜻 고르기 |

출제 순서와 보기 순서는 매판 랜덤.
